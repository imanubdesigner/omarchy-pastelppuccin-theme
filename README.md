## 🚀 Installation

Install directly via the Omarchy CLI:

```bash
omarchy theme install https://github.com/imanubdesigner/omarchy-pastelppuccin-theme
```

Then select **Pastelppuccin** from *Style > Theme* in the Omarchy menu.

## 🌿 Wallppuccin | The Official Wallpaper Companion

Looking for more wallpapers designed in the exact same spirit? **[Wallppuccin](https://github.com/imanubdesigner/wallppuccin)** is the dedicated wallpaper collection created to pair seamlessly with this theme.

Every shade in Pastelppuccin's `colors.toml` was carefully sampled and balanced against this collection of **213+ 4K wallpapers**:

- 🎨 **Tuned with PhotoCraft:** Recolored to soft, harmonious Catppuccin Mocha tones.
- 🖌️ **Hand-Retouched Details:** Subtle custom drawings, enhanced lighting, and touch-ups.
- 📐 **4K Standard (3840×2160):** Ultra-sharp across high-DPI displays.
